Detailní Průvodce: Uživatelská Rozhraní, Logika Bloků a AI Entit v Bedrocku
Tento dokument je specializovaným průvodcem pro tvorbu pokročilého UI (uživatelských rozhraní), state enginu pro vlastní bloky a AI/behaviorálních stromů pro entity v Minecraft Bedrock Edition.
1. Uživatelská Rozhraní (UI) a Návrhové Vzory
V Bedrocku máme k dispozici dvě cesty ke tvorbě rozhraní:
1. Scripting API (⁠@minecraft/server-ui⁠): Dynamické dialogy generované přímo ze skriptu (doporučeno pro systémy, shopy, questy).
2. JSON Custom UI (Resource Pack): Úprava nebo tvorba nativních herních obrazovek v RP pomocí ⁠.json⁠ souborů ve složce ⁠RP/ui/⁠.

B) Nativní Custom UI Soubory (Resource Pack)
Pro změnu nativních HUD prvků nebo inventářů upravujeme soubory ve složce ⁠RP/ui/⁠.
Nativní UI používá specifikaci JsonUI.
Základní principy JsonUI:
￼ ⁠controls⁠: Pole UI prvků (panely, texty, obrázky, tlačítka).
￼ ⁠bindings⁠: Propojení vlastností UI s vnitřními daty hry (např. zobrazení aktuálního počtu HP).
￼ ⁠size⁠ / ⁠offset⁠: Určení velikosti a pozice na obrazovce.
